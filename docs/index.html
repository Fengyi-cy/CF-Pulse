Zero-Friction CLI Setup

极速安装与纯净卸载

全平台原生支持，零多余依赖，不向系统注册表留存任何隐蔽文件。

terminal — zsh 
# 1. 克隆项目仓库
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse

# 2. 为可执行启动脚本与核心引擎赋予权限
chmod +x "CF优选测速.app/Contents/MacOS/CF优选测速"
chmod +x "CF优选测速.app/Contents/Resources/CloudflareSpeedTest/cfst"
xattr -cr "CF优选测速.app"

# 3. 双击 CF优选测速.app 即可自动在后台启动并唤起控制台！
# 1. Termux 更新基础环境
pkg update -y && pkg install git -y

# 2. 一键自动化部署配置
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse && bash install_android.sh

# 部署后自动注册全局 cfst 命令，并支持桌面微件一键静默拉起！
