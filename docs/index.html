内置多线程测速算法，在数万个 Anycast IP 中自动测出当前网络丢包最低、下载带宽最大的最佳入口。

极速安装与干净卸载

采用独立原生路线，零外部依赖。不向系统关键路径留存垃圾，随时可彻底清除。 

# 1. 克隆项目仓库到本地
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse

# 2. 为启动与测速核心赋予执行权限，并解除 Gatekeeper 隔离
chmod +x "CF优选测速.app/Contents/MacOS/CF优选测速"
chmod +x "CF优选测速.app/Contents/Resources/CloudflareSpeedTest/cfst"
xattr -cr "CF优选测速.app"

# 3. 运行体验：直接双击 CF优选测速.app 即可在后台静默运行并唤起控制台！
# 1. Termux 更新基础依赖
pkg update -y && pkg install git -y

# 2. 克隆仓库并一键自动化配置
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse && bash install_android.sh

# 提示：安装完成后自动唤起浏览器控制台，并支持桌面微件一键静默拉起！
🗑️ 彻底卸载承诺： Mac 直接将 App 移入废纸篓；安卓 Termux 执行一条命令即可 100% 抹平清除。
