提速核心

CDN 边缘节点优选：测出最快入口

针对不同宽带（电信/联通/移动）路由差异，自动在数万个 Cloudflare 候选 IP 中并发测速，测出你当前网络下跑得最快、延迟最低的入口 IP。

✔ 多线程并发测速：同时探测真实 TCP 延迟、丢包率与 HTTP 实际下载吞吐量；
✔ 自由灵活配置：支持自定义测速线程数、下载大小、延迟上限与带宽门槛；
✔ 一键保存导出：测速结果实时生成并自动保存，移动端一键导出至系统专属目录。
🛡️
防报错核心

ProxyIP 智能筛选：告别 Error 1000

针对访问 Cloudflare 托管网站（ChatGPT、Discord、Notion 等）容易触发的 DNS 回环报错，自动探测筛选优质反代出口，保障访问畅通无阻。

✔ 云端活跃池实时同步：自动拉取持续维护的活跃 ProxyIP 候选池；
✔ 原生并发 TLS 探针：秒级测试握手延迟、丢包率，剔除失效与高延迟反代；
✔ 机房与区域精准反解：实时向官方 Trace 反解落地机房代码（Colo）与归属国家。
🔍
深度诊断

全链路深度体检：诊断出口与解锁

单次测试即可同时探测节点访问不同网站的【原生出口】与【反代出口】双出站路径，精准排查分流配置是否正确，全面评估 IP 风控水平。

✔ 双通道出口并发捕获：清晰展现节点当前两个出口的真实 IP、机房与地理位置；
✔ IP 纯净度与欺诈评分：评估 0-100 欺诈值，辨别是机房还是住宅，标记风险标签；
✔ 关键 AI 与流媒体解锁：并发测试 Google、ChatGPT、Claude、Gemini 连通状态。

Fast Installation

极速安装与部署

复制以下命令，在你的 Mac 终端或安卓 Termux 中粘贴运行即可。

terminal — zsh 
# 1. 克隆项目仓库
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse

# 2. 为可执行启动脚本与核心引擎赋予权限
chmod +x "CF优选测速.app/Contents/MacOS/CF优选测速"
chmod +x "CF优选测速.app/Contents/Resources/CloudflareSpeedTest/cfst"
xattr -cr "CF优选测速.app"

# 3. 双击 CF优选测速.app 即可自动在后台静默运行并唤起浏览器控制台！
# 1. Termux 更新基础环境
pkg update -y && pkg install git -y

# 2. 一键自动化部署配置
git clone https://github.com/Fengyi-cy/CF-Pulse.git
cd CF-Pulse && bash install_android.sh

# 部署后自动注册全局 cfst 命令，并支持桌面微件一键静默拉起！
🗑️ 纯净卸载方式： Mac 直接将 App 移入废纸篓；安卓 Termux 执行一行命令即可彻底抹平。
